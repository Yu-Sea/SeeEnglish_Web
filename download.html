安装只需要三步

01 / DOWNLOAD

下载安装包

点击上方按钮下载 SeeEnglish-Setup-0.6.0.exe。文件会通过阿里云对象存储直接传输。

02 / INSTALL

运行安装程序

双击安装包，按向导完成安装。默认装到当前用户目录，不需要管理员权限，也不会改动系统级设置。

03 / START

开始记录

从桌面或开始菜单打开 SeeEnglish。首次启动会先准备本地服务，然后进入空白词库，直接开始记词。

Windows 可能提示“发布者未知”。
当前安装包尚未做代码签名，SmartScreen 会显示“Windows 已保护你的电脑”。这是未签名应用的正常提示；点击“更多信息 → 仍要运行”即可。安装包来自本页面的正式下载地址。

安装前后

系统要求

  • Windows 10 或 Windows 11（x64）
  • 约 300 MB 磁盘空间
  • 安装和运行时不需要联网
  • 不需要 Python、Node.js 或浏览器插件

数据与隐私

词库、复习记录、设置和本地 API 全部保存在本机。没有账号系统，也不会上传你的学习内容。卸载程序默认删除所有本地数据。
